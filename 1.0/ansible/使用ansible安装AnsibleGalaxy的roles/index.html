    使用ansible安装Ansible Galaxy的roles¶

    书接上回

    https://www.yuque.com/xianzhou-eiffx/aklhoc/vsz13ega7edlk67l?singleDoc# 《ansible基础》

    在安装好以上环境后

    Ansible Galaxy 是 Ansible 的一个社区平台，你可以在上面找到、下载、分享和使用由其他用户创建的 Ansible Role。Role 是一种将任务、处理器、变量和文件组织在一起的方式，便于重用和分享 Ansible 配置。

    要使用 Ansible Galaxy 里面的内容，你可以按照以下步骤操作：

    1. 浏览 Ansible Galaxy¶

    首先，访问 Ansible Galaxy 网站。在这里，你可以搜索你感兴趣的 Role，阅读它们的描述、README 文件、评分和评论，以及查看它们的源代码。

    一.案例1，给所有主机安装nginx¶

    2. 安装 Role¶

    找到你想要使用的 Role 后，你可以通过 Ansible Galaxy CLI（命令行界面）或者通过 Galaxy 网站的 UI 来安装它。这里介绍使用 CLI 的方法：

    • 通过 Ansible Galaxy CLI 安装 Role首先，确保你的系统上已经安装了 <font style="color:rgb(38, 38, 38);">ansible-galaxy</font> 命令。然后，你可以使用以下命令来安装 Role：
    ansible-galaxy install <username>.<rolename>

    其中 <font style="color:rgb(38, 38, 38);"><username></font> 是 Role 作者的用户名，<font style="color:rgb(38, 38, 38);"><rolename></font> 是 Role 的名称。例如，如果你想要安装一个名为 <font style="color:rgb(38, 38, 38);">geerlingguy.nginx</font> 的 Role，你可以运行：

    ansible-galaxy install geerlingguy.nginx

    Role 将会被安装到你的 Ansible 环境中的 <font style="color:rgb(38, 38, 38);">roles</font> 目录下（默认情况下是当前工作目录下的 <font style="color:rgb(38, 38, 38);">roles</font> 子目录）。

    3. 使用 Role¶

    安装完 Role 后，你可以在你的 Ansible Playbook 中引用它。创建一个新的 Playbook 文件（例如 <font style="color:rgb(38, 38, 38);">site.yml</font>），然后在其中使用 <font style="color:rgb(38, 38, 38);">roles</font> 关键字来包含 Role：

    - hosts: all
  roles:
    - geerlingguy.nginx

    这个 Playbook 将会在所有主机上应用 <font style="color:rgb(38, 38, 38);">geerlingguy.nginx</font> Role。

    4. 运行 Playbook¶

    最后，使用 <font style="color:rgb(38, 38, 38);">ansible-playbook</font> 命令来运行你的 Playbook：

    ansible-playbook site.yaml

    根据你的 Role 和 Playbook 的配置，Ansible 将会在被控制节点上执行相应的任务。

    二.案例2，给node2（database）服务器（172.16.120.250）安装mysql¶

    root@control /home/roles # ansible-galaxy install geerlingguy.mysql
- downloading role 'mysql', owned by geerlingguy
- downloading role from https://github.com/geerlingguy/ansible-role-mysql/archive/4.3.4.tar.gz
- extracting geerlingguy.mysql to /root/.ansible/roles/geerlingguy.mysql
- geerlingguy.mysql (4.3.4) was installed successfully
root@control /home/roles # ls
ible-galaxy info acandid.httpd  nginx  site.yaml
root@control /home/roles # vim site.yaml 
root@control /home/roles # cat site.yaml 
---
- hosts: database
  become: yes
  roles:
    - geerlingguy.mysql
  vars:
    mysql_root_password: 'Gww603397654'
    mysql_databases:
      - name: testdb
        encoding: utf8
        collation: utf8_general_ci
    mysql_users:
      - name: test
        password: 'Gww603397654'
        priv: 'testdb.*:ALL'
    mysql_remove_test_database: true
root@control /home/roles # ansible-playbook site.yaml
